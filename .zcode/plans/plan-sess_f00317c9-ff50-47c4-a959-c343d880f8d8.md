## 关键约定与风险

- **纯搬移**:函数体逐字保留,只改 use 块与必要的可见性(pub → pub(crate)/pub(super),兄弟模块互调时;子模块访问父模块私有字段/私有 fn 是 Rust 天然允许的,git/files.rs 已是先例)。
- **测试跟代码走**:各文件自己的 `#[cfg(test)] mod tests`;跨文件共用的测试辅助(temp_store、config_with_secrets、server() 等)放 `store/testutil.rs` / `agent/testutil.rs`(cfg(test) 下 pub(crate)),backup 的 source()/record() 只在 resolve.rs 用,就地放。
- **疑似死代码只搬不删**(store 的 encrypt/decrypt_sensitive_fields、agent 里 disk_summary 头上悬空的 `#[allow(dead_code)]`),重构不做行为判断。
- **主要风险**是搬漏 doc 注释或组错文件——用「拆前逐项列出原文件的全部 item,拆后逐项核对落位 + 测试数不变」兜底。
- 不做 git 提交(除非你要求);工作区已有未提交的 AGENTS.md 改动,更新会在其上继续。
- `engine.rs`/`pages.rs`/`container/mod.rs`/`git/mod.rs` 也偏大但不在本次范围,需要的话后续再做。
